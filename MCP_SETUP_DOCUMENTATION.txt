OVERVIEW
--------
This document covers the complete MCP integration for the Person Search 
application, including both Vercel-hosted and local MCP server configurations.

Project: Person Search Application
Database: Neon PostgreSQL (via Prisma ORM)
Deployment: Vercel
MCP Tools: CRUD operations for Person management


================================================================================
QUICK START - LOCAL MCP SERVER (RECOMMENDED FOR CLAUDE DESKTOP)
================================================================================

PREREQUISITES
-------------
1. Node.js 18+ installed
2. pnpm package manager
3. Claude Desktop application installed
4. Project environment variables configured (.env with DATABASE_URL)

STEP 1: VERIFY MCP SERVER FILE
-------------------------------
Ensure `mcp-server.js` exists in your project root with the following setup:
- Uses @modelcontextprotocol/sdk for MCP server
- Connects to Neon Database via Prisma Client
- Implements 5 CRUD tools: list_people, get_person, create_person, 
  update_person, delete_person

STEP 2: CONFIGURE CLAUDE DESKTOP
---------------------------------
Windows: Open %APPDATA%\Claude\claude_desktop_config.json
Mac/Linux: Open ~/Library/Application Support/Claude/claude_desktop_config.json

Add the following configuration (REPLACE PATH WITH YOUR ABSOLUTE PATH):

{
  "mcpServers": {
    "person-crud": {
      "command": "node",
      "args": [
        "C:\\Users\\ninomarcos\\Documents\\eca-projects-main\\person-search-basic\\mcp-server.js"
      ]
    }
  }
}

IMPORTANT NOTES:
- Use ABSOLUTE path to mcp-server.js
- Windows: Use double backslashes \\ or forward slashes /
- Mac/Linux: Use forward slashes /

STEP 3: TEST LOCALLY (OPTIONAL BUT RECOMMENDED)
------------------------------------------------
Before connecting Claude Desktop, test the server:

Command:
  node mcp-server.js

Expected Output:
  Person CRUD MCP Server running (connected to Neon DB)

Press Ctrl+C to stop. If errors occur, check:
- DATABASE_URL in .env file
- Prisma client generated (run: pnpm run db:generate)
- Node modules installed (run: pnpm install)

STEP 4: RESTART CLAUDE DESKTOP
-------------------------------
1. Completely close Claude Desktop (File > Quit)
2. Reopen Claude Desktop
3. Look for the 🔨 hammer icon in the bottom right corner
4. This indicates MCP tools are loaded

STEP 5: TEST MCP COMMANDS
--------------------------
Try these natural language commands in Claude Desktop:

Example Commands:
  "List all people in the database"
  "Show me the first 10 people"
  "Create a new person named Alice Johnson with email alice@example.com and phone 0412345678"
  "Get person with ID <paste-id-here>"
  "Update the person with ID <id> to change their email to newemail@example.com"
  "Delete person with ID <id>"


================================================================================
AVAILABLE MCP TOOLS
================================================================================

1. list_people
   Description: List all people or search by name
   Parameters:
     - query (optional): Search string to filter by name
     - limit (optional): Max results (default: 50, max: 100)
   Example: "List all people" or "Search for people named John"

2. get_person
   Description: Retrieve a specific person by ID
   Parameters:
     - id (required): Unique person identifier
   Example: "Show me person with ID abc123"

3. create_person
   Description: Add a new person to the database
   Parameters:
     - name (required): Full name
     - email (required): Email address
     - phoneNumber (required): Australian mobile (format: 04XXXXXXXX)
   Example: "Create person named Bob Smith, email bob@test.com, phone 0412345678"

4. update_person
   Description: Update existing person information
   Parameters:
     - id (required): Person ID to update
     - name (optional): New name
     - email (optional): New email
     - phoneNumber (optional): New phone number
   Example: "Update person <id> email to newemail@example.com"

5. delete_person
   Description: Remove a person from the database
   Parameters:
     - id (required): Person ID to delete
   Example: "Delete person with ID abc123"


================================================================================
VERCEL-HOSTED MCP (ALTERNATIVE SETUP)
================================================================================

OVERVIEW
--------
The application also supports MCP via Vercel deployment using mcp-remote.
This requires the mcp-remote npm package as a bridge between Claude Desktop
and the deployed Vercel endpoint.

INSTALLATION
------------
npm install -g mcp-remote

CONFIGURATION
-------------
Edit claude_desktop_config.json:

{
  "mcpServers": {
    "person-crud": {
      "command": "npx",
      "args": [
        "-y",
        "mcp-remote",
        "https://person-search-marcos-njps-projects.vercel.app/api/mcp"
      ]
    }
  }
}

DEPLOYMENT CONSIDERATIONS
-------------------------
- Vercel Deployment Protection may block unauthenticated requests
- For production use, disable Deployment Protection or configure bypass tokens
- Local MCP server is recommended for development and testing

PROJECT STRUCTURE
================================================================================

Key Files:
  mcp-server.js                    - Local MCP server (Node.js script)
  app/api/mcp/[transport]/route.ts - Vercel-hosted MCP handler
  app/api/people/route.ts          - REST API endpoint for people search

Database Schema (Person model):
  - id: String (UUID, primary key)
  - name: String (required)
  - email: String (required, unique)
  - phoneNumber: String (required)
  - createdAt: DateTime
  - updatedAt: DateTime

================================================================================
TROUBLESHOOTING
================================================================================

ISSUE: "Cannot find module '@prisma/client'"
SOLUTION: Run `pnpm run db:generate` to generate Prisma client

ISSUE: "MCP server not appearing in Claude Desktop"
SOLUTIONS:
  - Verify absolute path in claude_desktop_config.json
  - Check path uses proper separators (\\\ on Windows or /)
  - Completely restart Claude Desktop (Quit and reopen)
  - Check Node.js is installed and in PATH

ISSUE: "Database connection error"
SOLUTIONS:
  - Verify DATABASE_URL in .env file
  - Check Neon database is running and accessible
  - Ensure IP whitelist allows your connection (Neon settings)
  - Test connection: pnpm run db:studio

ISSUE: "EPERM operation not permitted" during build
SOLUTIONS:
  - Close any running node processes
  - Delete app/generated/prisma/*.tmp* files
  - Run: pnpm run db:generate
  - Retry build

ISSUE: "HTML authentication page returned instead of JSON"
SOLUTIONS:
  - This indicates Vercel Deployment Protection is enabled
  - Use local MCP server instead of Vercel endpoint
  - Or disable Deployment Protection in Vercel project settings

ISSUE: "Server disconnected" in Claude Desktop
SOLUTIONS:
  - Check mcp-server.js is running without errors
  - Verify DATABASE_URL is correct
  - Check Prisma client is generated
  - Review Node.js console for error messages


================================================================================
TECHNICAL IMPLEMENTATION DETAILS
================================================================================

MCP SERVER ARCHITECTURE
-----------------------
- Framework: Model Context Protocol SDK (@modelcontextprotocol/sdk)
- Transport: StdioServerTransport (stdio communication)
- Database: Prisma Client connecting to Neon PostgreSQL
- Process: Node.js standalone script

VERCEL DEPLOYMENT ARCHITECTURE
-------------------------------
- Handler: mcp-handler npm package (v1.0.3)
- Route: Next.js App Router API route
- Transport: SSE (Server-Sent Events) via [transport] dynamic segment
- Authentication: Next-Auth integration

DATA FLOW (Local MCP)
---------------------
Claude Desktop 
  → stdio → mcp-server.js (Node process)
  → Prisma Client
  → Neon PostgreSQL Database
  → Response back through chain

DATA FLOW (Vercel MCP)
----------------------
Claude Desktop 
  → mcp-remote (HTTP bridge)
  → Vercel API /api/mcp/[transport]
  → mcp-handler
  → Prisma Client
  → Neon PostgreSQL Database
  → Response back through chain

SECURITY NOTES
================================================================================

1. ENVIRONMENT VARIABLES

   Email format validated
   Required fields enforced
